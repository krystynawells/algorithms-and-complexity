## Featured Project: Fashion Trend Tracker

An interactive Python application that applies algorithms to analyse fashion trends, explore seasonal popularity and identify relationships between different styles.

Built using **Python and Marimo**, the project combines algorithm implementation, data visualisation and interactive exploration.

### Key Features

- **Merge Sort:** Ranks fashion trends according to their growth across seasons.
- **Linear & Binary Search:** Explores peak popularity and compares search performance.
- **Graph Algorithms:** Models relationships between fashion trends using adjacency lists and Breadth-First Search (BFS).
- **Perceptron Classification:** Implements a multiclass perceptron to classify fashion styles based on trend characteristics.
- **Complexity Analysis:** Evaluates algorithm performance through empirical timing experiments and theoretical complexity.
